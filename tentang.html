Tentang Saya

Kenali lebih dekat siapa saya dan apa yang saya kerjakan

Perjalanan Singkat

Saya adalah mahasiswa Universitas Pamulang (UNPAM) jurusan Teknik Informatika yang saat ini sedang menempuh Semester 5. Sembari menempuh pendidikan, saya juga aktif bekerja sebagai IT Infrastruktur di SMK Multidimensi Anyar.

Ketertarikan saya di dunia teknologi dimulai dari rasa penasaran tentang bagaimana sebuah website bisa bekerja. Dari situlah saya mulai belajar HTML, CSS, JavaScript, hingga akhirnya bisa membangun berbagai proyek web sederhana sampai menengah.

Di tempat kerja, saya bertanggung jawab menjaga kestabilan jaringan, mengelola perangkat lab komputer, serta memberikan dukungan teknis kepada guru dan siswa.
